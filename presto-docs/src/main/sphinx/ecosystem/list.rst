=========
Ecosystem
=========

Overview
--------

Here are some projects that support Presto:

* `APIJSON <https://github.com/Tencent/APIJSON>`_ : A JSON Transmission Protocol and an ORM Library that provides APIs and Docs without writing any code.

* `Hibernate <https://github.com/hibernate/hibernate-orm>`_ : Hibernate's core Object/Relational Mapping functionality.

* `OLake Go <https://olake.io/docs/>`_ : Open-source EL (Extract-Load) platform that replicates databases (PostgreSQL, MySQL, MongoDB, MSSQL, Oracle, DB2), Kafka, and S3 into Apache Iceberg tables using change data capture. Supports Iceberg catalogs that Presto reads, including AWS Glue, Hive Metastore, JDBC, and REST catalogs (Polaris, Nessie, Lakekeeper, and others). See the `OLake Go + Presto lakehouse guide <https://olake.io/blog/building-open-data-lakehouse-with-olake-presto/>`_ for a walkthrough of ingesting data from OLake Go into Iceberg via a REST catalog and querying it with Presto.
